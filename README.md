# 🧪 Compose Playground: Code Puzzle

Welcome to my **Playground Project**! This is my creative sandbox—a dedicated space for my free-time experiments, hobby coding, and exploring the bleeding edge of Android development.

## ⚠️ Disclaimer: The Experimental Zone
This project is **not** built on "Clean Architecture," "Production Best Practices," or "Optimized Solutions." 

**In my professional work, I follow those principles**, however, I do not follow the rules in this project, because **the priority of this project is**:
- Test **Alpha & Beta releases** (like Compose Navigation v3).
- Build **custom solutions** for things that already have libraries (like Drag & Drop reordering) just to see, what customization level it offers.
- Try new alpha releases for AndroidX libraries.
- Let my imagination run wild with UX/UI ideas.

---

## 🧩 The Project: Code Puzzle
The core logic is inspired by the **Code Puzzle** minigame from the board game *Mansions of Madness (2nd Edition)*. 

*   **Source Material:** [Mansions of Madness - Learn to Play](https://images-cdn.fantasyflightgames.com/filer_public/48/f4/48f426c2-b365-43be-abdd-03b2a55eb38d/mansions_of_madness_second_edition_learn_to_play.pdf)

## 💭 But why?: 

*  My wife absolutely loves this specific puzzle, so I decided to build a standalone Android version for her. It features customizable parameters and much "juicier" animations than the original digital companion app.

## 🛠 Tech Stack & Experiments
*   **100% Jetpack Compose:** Exploring the limits.
*   **Compose animations:** See what compose offers in animations, both pre-build and custom ones.
*   **Shared elements:** Taking closer look at shared elements between compose screens.
*   **Compose Navigation v3:** Testing the latest compose navigation v3.
*   **Custom Drag & Drop:** Built a custom reorder logic from scratch to understand the low-level touch handling and layout shifts.
*   **Rapid Prototyping:** Using this as a testbed for new AndroidX libraries before they hit stable.
